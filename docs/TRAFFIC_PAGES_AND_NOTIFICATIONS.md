# Zen 流量页面与通知

用户确认的结构：实时监控、历史分析、通知设置。原设备页地址作为隐藏别名保留，导航只显示三个入口。

| 页面 | 唯一职责 | 功能 |
| --- | --- | --- |
| 实时监控 | 现在谁在用网 | 当前全网互联网速率、最近 5 分钟速率曲线、按互联网速率排序的设备列表、在线状态、设备属性与改名；展开设备显示当前局域网速率 |
| 历史分析 | 过去用了多少 | 互联网日/月柱图、设备筛选、同窗口排名和 WAN 占比、未归属/超额说明、原有混合日/月记录、过去 7 天速率查询及明细；清空设备计数只在此页 |
| 通知设置 | 什么时候提醒、发到哪里 | 飞书/企业微信渠道、今日全网/指定 MAC 的上传/下载/总用量阈值、多规则、定时每日报告、显式连接测试、发送状态 |

首页概览仍保留原有摘要和图表。上述分工针对流量插件的三个页面；实时页没有历史日期查询或累计用量，历史页没有实时轮询设备表，通知页没有分析图表。

## 统计口径

新增 `wan_daily(date, mac, download_bytes, upload_bytes)`，空 MAC 表示上游接口总量，具体 MAC 表示 eBPF 归属的互联网流量。两类记录不能相加。每日数据从本版本启用、路由器时间有效时开始，旧 `daily_usage` / `monthly_usage` 的互联网＋局域网记录不会补入该表。启用首日可能不完整。

RAM 同时保存当前日与保留期内的已关闭日，批量 checkpoint 在原有事务中以绝对值 upsert，并写入 `wan_daily_since`。写入失败不会清空日记录；重启恢复、回拨重开日期和设备清零使用同一账本。每日记录保留 90 天，互联网月柱只是这些保留日期的月汇总；原有混合月记录仍保留 12 个月。

全网阈值采用上游接口今日用量；指定设备采用该 MAC 的今日互联网归属用量。占比使用同一份已保留日记录中的上游总量，未归属流量单独显示。设备归属计数大于上游总量时显示超额，不能假称设备总和永远等于 WAN。

## 设置与发送

- 默认关闭自动通知。保存立即生效，不重启采集。
- 可同时启用飞书、企业微信。仅接受其官方 HTTPS 机器人地址；不会跟随重定向。
- 飞书支持可选 HMAC-SHA256 签名。地址与密钥保存到 SQLite 设置表，读接口仅返回是否已配置，密码框留空保留原值；修改地址会清除原签名，输入 `-` 可显式清除签名。
- 配置与取消未发送队列在一次事务中提交。保存失败不替换内存中的设置。
- 阈值达到即提醒，每条规则、每个渠道、每个路由器本地日最多一个事件；编辑已发送规则不会在当天重新发送。取消但尚未发送的规则可以重新启用。
- 每日报告按路由器本地时间发送，内容是当天截至推送时间的全网上传/下载及设备前五。过时重启可补发当天未发报告，不补发往日；时钟无效不发。启用晚于当天推送时间时会发送当日报告。
- 后台线程使用 curl，连接超时 5 秒、请求超时 10 秒、响应上限 64 KiB，验证 TLS 证书与机器人 JSON 成功码。地址/消息通过标准输入传递，不进入命令行或日志；不启动 HTTP 服务、不使用 shell RPC 桥。
- 正常失败最多三次尝试（60 秒、300 秒重试间隔）。网络尝试之间至少 5 秒。存储失败至少 30 秒后再写，不因每秒采集刷盘。发送前必须持久化预约，保存失败不发消息。
- 成功去重状态与发送状态持久化，最近记录显示 30 条，保留 30 天。发送后、成功状态写回前掉电属于跨系统事务窗口，重启可能重复一次；第三方机器人无幂等键，不能承诺严格 exactly-once。
- 数据库及新建 WAL 使用仅 root 可读写权限。网页不会回显完整 Webhook/密钥；测试必须显式点击，且先保存修改。

飞书协议参考：[自定义机器人使用指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)、[官方签名示例](https://open.feishu.cn/community/articles/7271149634339422210)。企业微信协议参考：[消息推送配置说明](https://developer.work.weixin.qq.com/document/path/99110)；本次浏览器安全策略阻止读取该官方页面，未绕过限制。协议字段通过本地 TLS 模拟响应测试，真实用户渠道仍需配置后测试，不能声称已向真实企业微信群投递成功。

## 版本与验收状态

源代码版本：后台 `0.2.0-r10`，LuCI 流量插件 `0.2.0-r8`，主题维持 `0.2.0-r7`。这项改动包含 R9 的写满盘跨日期保留修复。

新增 Rust 验收：互联网日记录写失败与恢复/重启/日期回拨/清零，通知阈值与日报告跨重启去重，设置事务失败，签名向量，实际 curl 对本地 TLS 机器人服务器投递、证书拒绝与 HTTP 200 业务失败，重试上限、预约写入失败时禁止发送、存储失败 30 秒退避、后台线程成功消息跨重启去重，旧 WAL 权限和时钟无效守卫。上述测试均已由 CI [37143493429](https://github.com/zdabing/luci-zen/actions/runs/37143493429)（9ab9c0f）通过。
